# 杠杆交易安全清单

本清单针对 BTC/USDT、低频、3–10 倍杠杆、约 1000 USDT 资金规模的研究/模拟/Demo 系统。

## 实盘前必须满足

- [ ] 至少完成 3x、5x、10x 的 walk-forward 回测扫描；
- [ ] 策略在多个年份/行情阶段没有单一时期依赖；
- [ ] 已加入手续费、滑点和保守同K线触发规则；
- [ ] 本地模拟盘连续运行稳定；
- [ ] Demo/Testnet 订单、保护单、撤单、状态同步均验证过；
- [ ] 启动前 `scripts/deploy_check.py` 无 FAIL；
- [ ] 告警日志可正常写入；
- [ ] 断线恢复后不会重复开仓；
- [ ] 仓位不一致时只告警，不自动市价平仓；
- [ ] API Key 不写入代码和配置文件；
- [ ] 实盘 API 权限仅开放必要权限；
- [ ] 默认杠杆不超过 3x，10x 仅用于压力测试。

## V1.0 明确禁止

- 不做真实资金自动下单；
- 不自动开仓真实账户；
- 不自动市价平仓；
- 不绕过确认短语执行测试网交易；
- 不将 `allow_live_trading` 改为 true。

## 1000 USDT 资金规模建议

- 初始真实测试资金建议 100–200 USDT；
- 默认 1–3 倍；
- 单笔保证金比例不超过 20–30%；
- 发生连续亏损后暂停；
- 策略表现不稳定时优先降低杠杆，而不是提高阈值追求收益。
